# 📒 My Account Book

Spring Boot 기반의 자동 가계부 백엔드 프로젝트입니다.  
카드 사용 알림 데이터를 기반으로 지출을 자동 기록하고 분석하는 서비스를 목표로 합니다.

---

## 🚀 프로젝트 소개
이 프로젝트는 백엔드 개발 역량 강화를 위해 진행하는 개인 포트폴리오입니다.  
Spring Boot와 PostgreSQL을 활용하여 확장 가능한 가계부 시스템을 구축하는 것을 목표로 합니다.

---

## 🛠️ 기술 스택

| 구분 | 기술 |
|------|------|
| Language | Java 17 |
| Framework | Spring Boot |
| Database | PostgreSQL |
| ORM | Spring Data JPA |
| Build Tool | Gradle |
| IDE | IntelliJ IDEA |
| Container | Docker (예정) |
| DevOps | Kubernetes, GitHub Actions (예정) |
